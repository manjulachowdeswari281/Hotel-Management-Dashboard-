# Hotel Management System

A simple and responsive Hotel Management Dashboard developed using HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Room Management
- Booking Management
- Customer Management
- Revenue Analytics
- Add and Delete Bookings
- Search Customers and Rooms
- Automatic Room Availability Updates
- Local Storage for Saving Booking Data

## Project Structure
- index.html – Website structure
- style.css – Dashboard design
- script.js – Interactive functionality

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Explore the dashboard and test the features.

## Data Storage
Uses browser Local Storage to save booking details after refreshing the page.
